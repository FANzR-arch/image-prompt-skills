# Visual DNA Rules

## 先分清两类特征

### 不可变特征

用于维持"还是同一个对象"：

- 人物：脸部身份、年龄区间、发型、眼镜、肤色、标志服装与配饰。
- Logo：几何比例、负空间、字标关系、主色和核心轮廓。
- IP：头身比、轮廓、五官比例、主配色、服装与标志道具。
- 产品：外形、结构、材质、接口、标签层级与品牌标记。

### 可变特征

用于产生足够丰富的应用：

- 动作、表情、视角、镜头距离。
- 背景、光线、版式、应用载体。
- 辅助色、纹样密度、场景道具。
- 海报、包装、社交封面、空间和周边的具体呈现。

## DNA 卡必须可编译

DNA 卡不是给人看的总结，是**待写进五条提示词的原料**。每一项都要写成能直接搬进提示词的视觉事实，不能停在标签上。

| 不合格 | 合格 |
|---|---|
| 主色：橙色 | 主色：saturated warm orange `#F25C1F`，占画面 15–20% |
| 轮廓：几何感 | 轮廓：等边三角形去掉下半，切角 45°，负空间宽度等于笔画宽度 |
| 气质：理性 | 气质：cool, restrained, engineered — hard edges, no gradients, no ornament |
| 材质：质感好 | 材质：matte uncoated paper，微弱纸纹，无高光 |
| 发型：短发 | 发型：short black hair, side-parted, cropped above the ears |

**测试办法**：把 DNA 卡遮住参考图念一遍，如果一个没见过原图的人画不出来，这张卡就还没写完。

色值给不准时给色族加倾向（`warm orange, leaning red, high saturation`），不要瞎编十六进制——编错的色值比不给更糟，模型会当真。

## 输入路由

### Logo

把视觉基因重点放在形状语言、负空间、色彩、字体关系和重复方式。几何比例要**量化**——边长比、圆角半径、笔画粗细、字标与图形的间距关系。

不要强行把 Logo 变成人物。需要 IP 时，先从 Logo 轮廓中提炼角色结构，并说明这是衍生角色。

### 人物头像或个人形象

脸部身份优先级最高。风格化只能改变媒介与画法，不能把人物变成另一张脸。服装和标志性物件可作为个人品牌识别点。

**注意文字锚点的天花板**：文字锁不住脸。纯提示词交付时如实告知，见 `prompt-contract.md` 的诚实边界表。

### IP 或插画角色

优先锁定轮廓和头身比。复杂背景可以放弃，但角色比例、五官和道具不能漂移。头身比要给数字（`3-head-tall proportions`）。

### 产品或物件

先保证产品读得出来，再做品牌化。不要为了构图随意增加不存在的按钮、接口、包装文字或功能。

## 多参考图

- 指定一张主参考图锁身份。
- 其他图片只提供风格、色彩、材质或场景。
- 不把多个不同人物或角色平均融合成新对象，除非用户明确要求。
- 主辅关系要写进输出的"输入判断"里，让用户能否决。

## 手法与内容要拆开读

参考图里有两类信息，只有一类该被固化成 DNA：

- **手法**——媒介、边缘处理、光线性格、色彩关系、文字用法。这些是身份，写进 DNA 卡，五条提示词全部继承。
- **内容决策**——原图里那个具体的背景、那几件道具、那个姿势。这些跟着原图的当次用途走，**不是身份**，扩展时该换掉。

把内容决策当身份抄，是这套 skill 最常见的失败：五条图全在重复原参考图的那个场景，看起来像同一张图裁了五次，而不是一套系统。
