# Deliverables

五类输出各自的形态候选。**选之前先读输入类型**——同一类交付物，Logo 和人物头像该出的东西完全不同。

## 规模裁剪

五条是完整套装，不是最低配额。按用户实际要的东西给：

| 用户要什么 | 出几条 |
|---|---|
| "做一套完整的视觉身份" | 五条全出 |
| "给我做几张头像 / 几张海报" | 只出对应那一类，条数按用户说的 |
| "我要发小红书 / X" | 05 传播场景为主，加 01 主视觉打底 |
| "先看看能做成什么样" | 01 + 02 两条试水，用户点头再补齐 |

不硬凑五条。凑出来的那几条一定是把同一件事换个说法写了一遍，用户一眼看得出来。

## 01 主视觉

一张定调的图，后面四条都从它长出来。

- Logo：标识置于材质基底上的英雄图、大尺度局部裁切、标识与单一色块的构成关系。
- 人物：半身环境肖像、工作场景中的人、单色背景棚拍质感。
- IP：角色全身站姿定妆、角色在其标志性环境里的一个瞬间。
- 产品：单品英雄图、产品与其使用语境的一个静物关系。

## 02 视觉识别系统

平铺展示板。**必须规定面板数量和排列逻辑**，否则模型会给一堆糊在一起的缩略图。

- 3–5 个面板，网格排列，面板之间留明确间隔。
- Logo：主标识 / 单色版 / 最小尺寸版 / 色板条 / 安全边距示意。
- 人物：三种镜头距离 / 色板条 / 字体样张 / 常用版式框。
- IP：三视图 / 表情条 / 色板 / 比例尺。
- 产品：正侧背视角 / 材质样本 / 色板 / 尺寸标注。

色板条写成带色值的实心色块，不要写成抽象的"colour palette"。

## 03 变化系统

同一身份的 N 个状态并置。这条最容易漂——**每个变体都要重复一遍 identity lock**。

- Logo：辅助图形、纹样、图标族、标识的构成变体。**不默认把 Logo 变成人物角色**；用户要 IP 化时说明这是衍生角色。
- 人物：动作与表情设定，4–6 格。
- IP：姿态表 / 表情表 / 换装但不换身份。
- 产品：视角变化、细节特写、配色变体、季节主题变体。

## 04 应用系统

落到实物或数字载体上。**先按品类挑，不要每次都退回马克杯、T 恤、帆布袋。**

按输入类型和使用目标挑 2–4 件，组成一张应用板或分别成图：

- **纸品**：名片、信封、贴纸、票券、明信片、说明卡、书籍腰封。
- **包装**：纸盒、软包、瓶贴、封缄贴、外箱、缓冲纸。
- **数字**：App 图标、启动页、网页 hero、后台侧栏、Keynote 首页、邮件页头。
- **穿戴与随身**：工牌、帆布包、卫衣、棒球帽、徽章、钥匙扣。
- **空间**：门头、指示牌、展台背板、灯箱、橱窗贴。
- **内容账号**：头像、封面横幅、直播背景、片头板、字幕条、缩略图模板。

个人品牌选数字 + 内容账号；商业品牌选纸品 + 包装；产品选包装 + 数字；IP 选穿戴 + 纸品。

## 05 传播场景

放进真实语境里，有环境光、有手、有桌面、有屏幕。这条决定整套东西"像不像真的"。

- 手持视角：手拿名片 / 手机屏上的账号页 / 手举包装。
- 桌面场景：工作台俯拍，物件与日常道具共存。
- 街头与空间：门头实拍视角、地铁灯箱、货架陈列。
- 屏幕内：社交平台信息流截图感、账号主页、视频封面在推荐墙里。
- 人物在场：人穿着 / 使用 / 展示这套东西。

**环境要给真实光线**（窗光、店铺射灯、屏幕冷光），不要写成 studio lighting——那会退回 02 的展示板质感，这条就白做了。
