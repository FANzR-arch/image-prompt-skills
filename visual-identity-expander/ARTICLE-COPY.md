# 一张图扩展成一套视觉身份：简易复制版

上传一张能够代表你、品牌、角色或产品的图片，然后把下面整段复制给 AI。

```text
请把我上传的图片当作「视觉母体」，先判断它属于 Logo、人物头像、个人形象、IP 角色、插画、产品还是标志性物件，再提取其中可以持续复用的视觉基因。

第一步，区分两类信息：
1. 必须保留：身份、核心轮廓、五官或几何比例、主色、标志性服装或道具、材质、品牌文字。
2. 可以变化：动作、表情、镜头、版式、背景、应用载体和传播场景。

第二步，输出一张「视觉 DNA 卡」。每一项都要写成具体的视觉事实，不能停在标签上——不要写「橙色」，要写「饱和暖橙 #F25C1F，占画面 15% 到 20%」；不要写「几何感」，要写「等边三角形去掉下半，切角 45 度」。测试办法：遮住原图念一遍这张卡，一个没见过原图的人要能照着画出来。色值拿不准就描述色族和倾向，不要瞎编十六进制。

第三步，基于同一套视觉规则，生成五条可以直接用于生图的完整提示词：
1. 品牌或个人主视觉；
2. 视觉识别系统展示板（规定面板数量和排列方式）；
3. 角色动作、辅助图形或产品变化系统；
4. 包装、周边、数字产品或其他应用场景；
5. 社交媒体封面、海报或真实传播场景（要有真实环境光，不要写成棚拍打光）。

每条提示词按这七段写，带上段落标签：Use case / Scene / Subject / Key details / Composition / Text in image / Constraints。

关键要求：
- 身份必须写在提示词文字里，写到自足。不要用「参考我上传的图片」「保持上一张的风格」这种话来承载身份，否则这条提示词离开这次对话就没用了。
- 五条提示词共用一套基座：不可变特征清单、色板与材质、身份纪律。这三段要一字不差地重复写进每一条，不要写「同上」——AI 生图时一次只看得见一条。
- 排除项写进 Constraints 那一段的正文，用 no 开头，不要单独输出 Negative prompt 块。
- 不要用 masterpiece、8k、ultra detailed 这类空词，换成具体的视觉事实。
- 画面里要出现的文字只用我提供的原文，加上「render all text verbatim, no extra words」。我没给文字就写 no text，不要编造品牌名或口号。
- 成品里不要留括号占位符、斜杠菜单或未决定的选项。

最后检查五条提示词在身份、轮廓、色彩、文字和气质上是否一致。如果我上传的是人物照片，请提醒我：文字描述保得住发型、眼镜、服装和气质，保不住同一张脸。
```

## 更完整的 Skill

支持 Agent Skills 的工具可以安装整个 `visual-identity-expander/` 目录。完整版本会根据 Logo、人物、IP 和产品自动切换延展逻辑，按你实际要的东西裁剪输出条数，并提供载体词汇表、一致性检查和修正规则。

触发示例：

```text
用 visual-identity-expander，把我上传的头像扩展成一套个人品牌视觉提示词。
```

```text
用 visual-identity-expander，把这个 Logo 扩展成主视觉、辅助图形、包装和社交媒体视觉。
```

```text
用 visual-identity-expander，我只要三张贴纸和一张动作设定板，不用出全套。
```
