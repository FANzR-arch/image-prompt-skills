# Flat Field Cover Poster（平涂色场杂志封面编译器）

把**一个主题**编译成**一条**可直接交给图像模型的提示词。风格锁死：一块纯平色底，一个写实人像，一行超大压缩体标题被人的头肩截断，一个手绘元素压在前景下角。

核心原则：**一块色，三层质感，一次遮挡。**

这套风格的高级感不来自元素多，来自三件事同时成立——底色绝对平（没有渐变、没有场景、没有暗角）；照片层、平面色层、手绘层三种质感同框但各自保持身份，不互相融合；标题第二行**必须真的被头肩挡住**。任何一条塌，就退回成普通的加字海报。

## 画幅

**2:3 竖版锁死。** 出图参数用 `2048×3072`、quality `high`——占位文本行、刻度行和压缩体的细窄字腔都吃分辨率，低分辨率下这些细节必糊成噪点。

其他画幅未经验证；用户明确要求才改，并提醒排版系统的边距比例需重新量。

## 两个排版寄存器（Register）

一次选一个，整组统一。选定后**四处联动同改**，不能只改一处。

- **CLEAN（默认）**：细线、宽边距、严格对齐网格、序号在右缘、刻度行落左下。适合时尚、美妆、文化、访谈。
- **ROUGH**：粗线、紧边距、元素轻微出格、序号在左缘、刻度行落右下（相对 CLEAN 整体镜像）。适合运动、街头、青年文化。

寄存器只改排版纪律，不改色场逻辑和遮挡结构。

## Read

- 编译提示词：读 `references/compile-contract.md`（铁律 + 锁死内核 + 两寄存器 + 固定骨架）。
- 选色底、桥接元素、机位，或成组批量做：读 `references/registers.md`（四张模块表）。
- 要已验证的成品参考：读 `references/examples.md`（四条实测 prompt 原文）。

## Input

从用户输入推断，不要求填表：

1. **标题两词**：第一行短词、第二行长词。第二行是承重项——它必须够宽才会被头肩截断。约束见 compile-contract。
2. **品类标签**：左上角那行 `<X> FEATURE`。用户没给就按主题拟一个。
3. **色场寄存器**：查 `registers.md` 的色场表。四套已验证，四套待验证。
4. **主体**：人物 + 景别 + 姿态 + 手部处理。
5. **桥接元素**：主题的物质隐喻，且必须和主体身上的某样东西同源。
6. **排版寄存器**：CLEAN 或 ROUGH。

## Workflow

1. **定色场**：先定底色和三色板，它决定标题色和整张图的影调。色板一旦定死，后面所有槽位都只能在这三个色相里选。
2. **定主体与机位**：查机位表。手部必须当场决定——不入画，或者明确抓着一件叫得出名字的东西。没有第三种。
3. **定桥接元素**：这是全套的命门。它要同时满足两条——是主题的物质隐喻，且和主体身上某样东西同源（裙子的水彩印花 ↔ 前景的水彩花枝）。找不到同源关系就换元素，不要硬放一个装饰。
4. **定桥接位置**：放在**光源的对侧下角**。光从右上来，元素落左下。
5. **定标题两词**：查选词约束。第二行长度不够就换词，不要指望模型自己调整。
6. **编译提示词**：按 `compile-contract.md` 的固定骨架输出成品，无占位符、无菜单、正文零中文（渲染标题除外）。
7. **输出**：寄存器 + 一条完整提示词 +（可选）一句色场与桥接元素的选型理由。用户只要 prompt 时省略解释。

**成组产出时**：风格基座（Scene 结构 / Composition / Text 规格 / Constraints 四段）必须逐字写进**每一条**提示词——模型只看得见单条，共享规则不会自动继承。每张之间只换色场、主体、桥接元素和两词标题。

## Quality Gates

- **底色纯平**：出现渐变、暗角、纹理或任何景物即失败。这是本风格的第一承重墙。
- **遮挡必须发生**：标题第二行要有字母被头肩真实截断。全部压在人前、或全部退到人后，两种都算失败——这是本风格的身份特征，没有它就只是一张加了字的照片。
- **三色板闭合**：全画面只有三个色相。出现第四个色相即失败，最常见的是背景漏进环境色或服装带进杂色。
- **桥接元素必须是绘画**：它要明确读作手绘/水彩/水墨/马克笔，且**压在照片前面**。被渲染成真实物体（水彩花枝变成一枝真花）是本风格最高频的塌方点，必须在 Constraints 里按名封堵。
- **占位文本不可读**：小文本块必须是不成词的占位行。出现任何可读单词即失败。
- **手部有交代**：不入画，或明确持物。手在画面里松散地摊着是废图率最高的情形。
- **文字精确**：只出现标题两行、品类标签、三个序号。出现第四类文字、水印、logo 即失败。
- 本 skill 只产出提示词，不编造已生成的图片结果。
