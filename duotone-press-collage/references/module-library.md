# 模块库

五张表：色寄存器 / 器物母题 / 连接物 / 装饰装置 / 标签块。成组产出时前三张表逐张重抽，不重复。

## 一 · 色寄存器

`{{GROUND}}` 与 `{{SPOT}}` 成对使用。专色只给连接物和第二色版，不给背景、不给器物金属。

| 寄存器 | GROUND | SPOT | METAL | 气质 |
|---|---|---|---|---|
| R1 油墨黑 | `ink black` | `rust orange` | `steel grey` | 最重，适合封面 |
| R2 暗酒红 | `oxblood` | `mustard yellow` | `warm grey` | 有温度的重，首图用的就是它 |
| R3 深墨绿 | `deep pine green` | `deep teal` | `brass ochre` | 车间感，适合工序类小节 |
| R4 钴蓝 | `cobalt blue` | `signal red` | `steel grey` | 冷底配警示红，适合"要改哪里" |
| R5 焦赭 | `burnt ochre` | `brick red` | `steel grey` | 暖，适合"代价 / 积累"类 |
| R6 暖石灰 | `warm slate grey` | `signal red` | `brass ochre` | 中性，适合"识别 / 检验"类 |
| R7 骨白 | `pale bone grey` | `rust orange` | `cool steel grey` | 最亮，适合"太整齐 / 空"类 |

**成组配色规则**：一套图里 GROUND 全部不同；SPOT 允许复用一次但不相邻。封面优先取 R1 / R2 这类重底。

## 二 · 器物母题库

限定在工坊 / 度量 / 检验家族。每张图取**一个主物件**（有内部结构）+ **一到两个配角**。

| 家族 | 器物 |
|---|---|
| 排版与印刷 | 活字排版盘、单枚铅字、排字规、凸版打样机、墨辊、样张、废样张 |
| 检验与度量 | 检品灯箱、放大镜、天平、秒表、卡尺、玻璃温度计、色卡、密度计 |
| 校对与批注 | 校对红蓝铅笔、蜡笔圈画、校对符号、钢尺、方格校对纸 |
| 票据与纸品 | 票据穿刺针、旧收据、蜡封信、折叠地图、卡片盒、订书机 |
| 老式机械 | 打字机、传声筒喇叭、编织电话线、投币售货柜、齿轮组 |

**回滑封堵清单**：以下器物永远不用，且写进 Constraints —— 复古电视机 / CRT 电脑、锡皮机器人、地球仪、洒水壶、盆栽、老式相机、留声机。它们是"通用复古素材"，一出现整套风格塌成廉价怀旧。

**主物件必须能被叫出名字。**抽象几何形披上网点不算物件——读者先认物、再解意，认不出后面全断。

## 三 · 连接物库

这是本风格的承重模块。**每张图必须有且只有一件。**

| 连接物 | 表达的关系 | 写法要点 |
|---|---|---|
| 绷紧的线 / 绳 | 牵引、因果 | 写清从哪个部位出发、系在哪里，`taut` 而非 `loose` |
| 垂坠的编织线 | 传导、通话 | 写出下垂最低点落在画面高度百分之几 |
| 送入 / 吐出的纸带 | 输入输出 | 写清进入方向和出口部位 |
| 杠杆被压下 | 触发、动作发生 | 写 `pulled down`，并写出结果物件 |
| 悬空未落的东西 | 尚未发生、差一步 | 写 `suspended in the air above`，写清它将落到哪里 |
| 颜色的断点 | 骤变、降温 | 写 `abruptly drops`，写清断点在纵向百分之几 |
| 物理反常 | 反直觉的判断 | 例：堆满的一侧翘起、单枚的一侧沉底。写清违反的是什么常识 |
| 引线 + 编号圈 | 指认、逐项 | 写清引线终止在页边，圈里印数字 |
| 磨损对比 | 时间、代价 | 同一物件的两种状态并置，写清边缘差异（起毛磨破 vs 四角笔挺） |
| 虚线路径 + 图钉 | 定位、找到 | 路径要跨过至少两个区块再终止 |

**并置不算连接物。**两件东西放在一起而没有可见的连接，读者不会自己推断关系。

## 四 · 装饰装置

印刷生产语汇。**每张只取 2–3 件**，全上就变素材墙。

| 装置 | 英文 | 惯用位置 |
|---|---|---|
| 裁切角线 | `crop marks at the four corners` | 四角，几乎每张都带 |
| 套版十字线 | `a {{SPOT}} registration crosshair` | 单角，一枚 |
| 六格色条 | `a six-swatch colour control bar` | 沿某一边，一条 |
| 胶带 | `a strip of masking tape holding a scrap down` | 压住某张纸片 |
| 订书钉 | `one stapled kraft corner` | 单角 |
| 撕纸条 | `torn pulp-paper strips` | 固定项，每张都带 |
| 黑色实心三角 | `one black triangle` | 单个，降权使用 |

前两项 + 撕纸条是稳定组合。三角和锯齿线是上代语汇的残留，只作单点点缀，不要成组撒。

## 五 · 标签块规格（固定，不换）

```
white heavy Chinese sans-serif inside a solid black rectangle with a {{SPOT}} vertical bar
along its left edge and a clipped upper-right corner: "<标签>"
```

四项必须齐：黑矩形 / 专色左竖条 / 右上切角 / 白色重量级中文。缺一项就退化成普通黑标签。

- 文字 **2–4 字**，用户原文照抄，不润色。
- 位置只取 `lower right` 或 `lower left`。成组时可交替，但同一套里不要超过两种位置。
- 封面不用标签块，用四层文字（见 `compile-contract.md`）。

## 六 · 器物上的文字

物件上印字是合法手法，也是这套风格的信息密度来源。密度按篇定。

| 类型 | 用法 | 风险 |
|---|---|---|
| 数字与刻度 | 温度计刻度、秒表表盘、编号圈 | 低，稳定 |
| 等宽短标签 | 地图格子里的路径名、票据字段 | 低 |
| 印章大写 | `OK`、`REJECTED` | 低 |
| 完整命令行 / URL | 样张上印一行 | **高**，必须逐字符核，错一个即重出 |
| 不可读占位 | `smudged illegible lines`、`solid black bars carrying no readable letters` | 无风险，且是正解 |

**抽象量用可读的字和数，不用抽象图形**——缩略尺寸下抽象条形和微型图标会退化成纹理，直接印数字和短标签更可靠。

**正文的大段文字一律走占位**：写成等长黑条或晕开的墨迹，不要让模型生成可读段落。
