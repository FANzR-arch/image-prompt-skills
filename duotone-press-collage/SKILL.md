# Duotone Press Collage（双色套印拼贴编译器）

把一个主题编译成**一条**可直接生图的提示词。媒介锁死、器物和配色可换：纯色平涂底上贴一组粗网点双色套印的实物剪影，每件带白色刀切描边，一件可见的连接物把它们串成一句话。

核心原则：**网点只长在剪贴物上。** 平涂色场必须绝对干净——这是这套风格既有印刷质感又不脏的唯一原因，也是最常见的失手。模型的默认行为是把全画面统一成一种质感，不显式排除就一定会长满。

第二原则：**关系要画出来。** 并置不等于关系，观众不会自己推断。每张图必须有一件可见的连接物——绳、线、纸带、杠杆、落下的东西、颜色的断点。没有连接物的画面是素材摆拍，不是论点。

## 画幅

| 交付物 | 比例 | size | quality |
|---|---|---|---|
| 文章封面横幅 | 5:2 | `3840×1536` | high |
| 章节配图 | 16:9 | `3840×2160` | high |

quality 一律 high。网点密度、套印偏移、器物上的小字都吃分辨率，medium 以下网点糊成灰块、刻度和命令行烂掉。

方图不可用——这套风格靠横向的物件调度和层压叙事，压成方图会挤死。

## 风格 DNA（八项，换任何主题不变）

1. **双色套印半调**：每件实物是照片翻成粗网点，黑版 + 一个专色版，专色相对黑版偏移 1–2px，全尺寸下错位清晰可见。这是本风格的定义特征。
2. **白色刀切描边**：每件剪贴物外围一圈 3px 白色贴纸描边 + 一道极浅硬投影。描边只跟剪贴物，**不跟平涂色块、不跟背景纸片以外的东西**。
3. **锐边不被纹理侵蚀**，且**锐点必须逐个点名**——尖端、边角、硬转折写进 Key details，不点名会被整体质感抹平。
4. **网点作用域只有剪贴物与纸片**。平涂色场无网点。纸纤维覆盖全画面，这是唯一的全域纹理。
5. **五角色色板，一色一职**：ground（平涂底）、纸质中性（pulp off-white / kraft）、单一专色（只给连接物和第二色版）、器物金属色（brass ochre 或 steel grey）、黑（几何装饰 + 文字块）。
6. **印刷生产装饰语汇**：裁切角线、套版十字线、六格色条、胶带、订书钉。**每张只取 2–3 件**，全上就变素材墙。
7. **标签块规格固定**：黑色实心矩形 + 左缘一条专色竖条 + 右上角切角 + 白色重量级中文，2–4 字。
8. **器物限定在工坊 / 度量 / 检验家族**：印刷器具、量具、仪器、票据、纸品、老式机械。跨出这个家族（复古家电、机器人、地球仪、盆栽）风格立刻塌成通用复古素材。

第 4 条最容易丢，第 8 条其次。

## 质感四维（一维一答，不留空）

| 维度 | 本风格取值 |
|---|---|
| 形体简化度 | **不简化**。保留照片轮廓，靠网点降信息量。不是几何化、不是 low-poly |
| 边缘处理 | 刀切锐边 + 3px 白描边 + 浅硬投影。边缘绝不被纹理侵蚀 |
| 纹理性质 | 粗网点双色套印（网点肉眼可见 + 版间偏移）+ 纸纤维 |
| 纹理作用域 | 网点只在剪贴物与纸片；纸纤维全域；平涂色场无网点 |

四维互相联动。**修质感必须整段重写，不逐词打补丁。**

## Input

从用户输入推断，不要求填表：

1. **主题**：决定器物、连接物和文字。
2. **这一节的判断**：一句话说清这张图要成立的是什么主张——决定连接物怎么选。用户没给就从上下文提。
3. **标签文字**：2–4 字中文，用户原文照抄，不润色。
4. **色寄存器**：用户没指定就按主题气质选；成组产出时逐张换，不重复。

## Workflow

1. **先写这一节的判断**（一句话）。跳过这步会得到一堆好看但不说话的复古器物。
2. **选连接物**——绳 / 线 / 纸带 / 杠杆 / 落下的东西 / 颜色断点 / 物理反常。连接物决定构图骨架。
3. **选器物**：一个有内部结构的主物件 + 一到两个配角。主物件必须能被叫出名字。
4. **选色寄存器 + 专色**。成组时先把整组抽取结果列成表，确认背景色和专色都不重复再编译。
5. **点名锐点**：这张图里哪几处必须保持锐利，逐个写进 Key details。
6. **量测占比**：主体横向占宽、上下缘落在画面高度百分之几、旋转角度，写进 Composition。不靠印象估。
7. **编译**：按 `compile-contract.md` 的七段骨架输出，基座逐字带全，无占位符、无菜单、正文零中文（渲染文字除外）。
8. **过 Quality Gates**。

**成组产出时**：Key details / Constraints 两段基座必须逐字写进**每一条**提示词——模型只看得见单条，共享规则不会自动继承。只有 Scene 的色彩变量、Subject 的器物和情节、Composition 的占比、Text 变。

## Quality Gates

出图后逐条核：

- **背景无网点**。平涂色场上出现任何点、颗粒、纹理即失败，这是第一失败点。
- **套印偏移可见**。全尺寸下看得到黑版与专色版的错位；看不到就是这一维没生效。
- **描边归属**。白色刀切边只在剪贴物轮廓上，没有爬到平涂色块或背景上。
- **锐点还在**。点名过的尖端、边角、刻度线没有被网点糊掉。
- **连接物成立**。能一眼看出谁连着谁、朝哪个方向。看不出就是这张图没说话。
- **专色归位**。专色只在连接物和第二色版上，没有跑到背景或器物金属上。
- **标签块规格**：黑矩形 + 专色左竖条 + 右上切角 + 白字，四项齐。
- **文字逐字对**。命令行、URL、数字、刻度必须逐字符核，错一个即重出。
- **器物没有回滑**：没有出现复古家电、机器人、地球仪、洒水壶这类通用复古素材。
- 本 skill 只产出提示词，不编造已生成的图片结果。

首图暴露一点，已回写：**「放大镜下网点更粗」这类局部密度差要显式写成"比全图粗几倍"**，只写 magnified 会得到一个普通放大效果，看不出机械感。

| 风险 | 状态 / 怎么修 |
|---|---|
| 背景长满网点 | 高危。Constraints 基座已封堵。仍犯则把 `flat colour field carries no dots` 提到 Key details 段首 |
| 套印偏移糊掉整张 | 双色是新增维度，**出图糊了先只删这一维**再看，不要整段重写质感 |
| 同形状复制多份退化成纹理 | 堆积类主体（一堆铅字、一沓票据）必须点名保住每一件的轮廓线。仍糊则减数量，不加修饰 |
| 器物滑回通用复古素材 | Constraints 基座按名封堵。成组时把上一版用过的器物也追加进封堵清单 |
| 中文标签块字形 | 首图已验证 5:2 封面标题与标签正常。16:9 章节图的小字标签块**未单独验证** |
| 长命令 / URL 印错 | 必须逐字符核。连续失败就缩短到最短可辨识片段，不要拆字形描述 |
| 成组撞脸 | 背景色、专色、连接物三张表每张重抽，不重复 |

## Guardrails

- 风格用视觉特征描述，不指名艺术家。
- 器物是泛型物件，不复刻真实品牌标识；确需真 logo 的场合走 `gpt-image-prompt-spec` 的全量还原路径（点名品牌与版本，不拆字形、不留白后期合成）。
- 出图偏差先怀疑 Subject 槽点名不足，不要动 DNA 固定块；**一轮只改一处**，质感维度例外（整段同改）。
- 效果不对时先删修饰再加修饰。修饰词过多会互相竞争。
- 已验证有效的提示词不为了合规去改。回退到最近的已知良好版本是合法且常常最优的动作。
