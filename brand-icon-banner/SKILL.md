# Brand Icon Banner（立体品牌图标横幅编译器）

把**一条关于某个平台/产品的判断**编译成**一条**可直接交给图像模型的提示词。风格锁死：近白影棚虚空，右侧悬一枚厚圆角立体 App 图标载着真实品牌 logo，左侧三层中文文字压在同一条水平轴上。

核心原则：**一个图标，一块反白，一条水平轴。** 这套风格的干净感不来自元素少，来自**结构对齐**——文字块和图标共享一条光心线，强调色只出现在一处（反白块），道具不超过两件。加第二个主体、让强调色散到三四处、让投影爬进文字区，风格立刻塌。

## 画幅

**5:2 超宽横板锁死。** 出图参数用 `2560×1024`、quality `high`——中文密排小字和图标倒角的窄高光都吃分辨率。

其他画幅未经验证；用户明确要求才改，并提醒留白比例和文字块宽度上限需重新量。

## Logo 协议（本 skill 的命门）

这套风格的全部识别度压在那枚 logo 上，所以它有独立的四条规矩：

1. **先调研当前版本再落笔**。品牌会改标（Twitter → X）、同时存在多套版本（App 图标版 / 横排字标 / 深底浅底版）、也可能刚改过版。确认现在在用的是哪一版，**点名到版本**：`the current X app icon`、`the current 小红书 app icon`。
2. **直接点名，不拆字形**。写 `the X logo` 就够，模型认得。拆成笔画、交角、笔画末端怎么切——写得越细画得越歪。
3. **只补呈现方式**：什么颜色、贴在哪个面、占该面多大比例、是否随主体透视旋转、有没有浮雕或描边。
4. **把退役旧标按名封堵进 Constraints**。模型的默认值经常停在旧版，X 会出蓝鸟，微博会出旧眼睛标。这条是必需项不是保险。

另有一条渲染纪律写进 Constraints：**logo 必须平贴正面、不得随倒角包裹或拉伸变形**——3D 面贴标最高发的坏法就是这个。

## 配色寄存器：跟品牌走

配色不预设，**由品牌主色决定**，但架构固定为四角色：

| 角色 | 取值 | 面积 |
|---|---|---|
| 底 | 近白影棚（冷白或暖白，跟品牌调性） | ≈85% |
| 主体三档 | 品牌主色的正面 / 侧面 / 底面三级明度，**必须分开给值** | 图标 |
| 强调 | 纯黑或品牌主色，只出现在文字里的三处 | 极小 |
| 次要文字 | 冷中灰 `#6B7280` | 小 |

**三档明度是承重项**。只给一个品牌色，立体图标会塌成一块平面色片——正面 / 侧面 / 底面必须各差一档。品牌色是黑白系（X、Apple）时更要给死，否则整枚图标糊成一坨。

## 反白块：强调装置

大标题里被强调的词**不用变色，用反白块**——纯黑（或品牌主色）实心圆角矩形 + 白字。这是这套风格区别于「大字加彩色关键词」的地方，也是它在缩略尺寸下仍然读得出重音的原因。

有块就不要括号。`「共用实名」新政策` 应编译成 `[创作者分成]新规则` 的形态——方块承担了引号的职能。

## Read

- 编译提示词：读 `references/compile-contract.md`（固定骨架 + 全部数值 + 七槽全文）。
- 选道具、要品牌寄存器、要成品参考：读 `references/examples.md`（品牌寄存器表 + 道具映射表 + 已验证成品 prompt）。

## Input

从用户输入推断，不要求填表：

1. **品牌**：这篇讲的是哪个平台/产品。先调研它当前的 logo 版本。
2. **大标题**：强调词 + 尾词，节奏是「四到五字 + 三字」。强调词进反白块。超过五字反白块会长到压掉右侧留白。
3. **kicker**：标题上方的小标签，≤4 字。成系列时它是常量（如「平台观察」）。
4. **副标题**：≤10 字。成系列时它也常是常量。
5. **道具**：按主题从道具表选 1–2 件，上限两件。

## Workflow

1. **调研 logo**：确认品牌当前在用的标识版本，以及有没有需要封堵的退役旧标。
2. **定三档明度**：取品牌主色，给出正面 / 侧面 / 底面三个色值。
3. **选道具**：查 `examples.md` 的道具映射表，按文章主题选 1–2 件。道具是意义层，不是装饰。
4. **压标题**：把判断压成「强调词 + 尾词」，强调词进反白块。
5. **编译提示词**：按 `compile-contract.md` 的固定骨架输出成品，无占位符、无菜单、正文零中文（渲染文字除外）。
6. **输出**：一条完整提示词 + 参数 +（可选）一句道具选型理由。用户只要 prompt 时省略解释。

**成组产出时**：Key details、Composition、Text 规格、Constraints 四段必须逐字写进**每一条**提示词——模型只看得见单条，共享规则不会自动继承。只有品牌名、三档色值、道具和文字变。

## Quality Gates

- **logo 保真**：出图后核对 logo 是不是当前版本、有没有被倒角拉变形、有没有退回旧标。这三处任一错，整张作废重生成——这套风格的全部说服力在这里。
- **三档明度分离**：图标的正面 / 侧面 / 底面能不能读出三个层次。塌成一片即失败。
- **一条水平轴**：大标题的中线和图标的光心必须同高。差一点就散，这是最容易被模型自由发挥掉的一处。
- **投影不进文字区**：主光在左上，投影落右下，绝不能爬到左侧文字块上。
- **强调只有一处**：反白块是画面唯一的重音。副标题的 `&` 和上方那道细线是次级点缀，不算第三处强调。
- **道具 ≤2 件**：超过两件主体的主角地位就塌，画面从"场景"退化成"堆砌"。
- **中文精确**：只出现指定的三行，必带 verbatim 条款。画面里出现第四行字、水印或多余标点即失败。
- 本 skill 只产出提示词，不编造已生成的图片结果。
