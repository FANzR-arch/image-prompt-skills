# Engineering Blueprint Sheet（工程图纸编译器）

把一个东西编译成**一条**可直接交给图像模型的提示词，风格锁死为「一张真的工程图纸」：不是加个蓝色滤镜，是按制图规范画——线型分级、尺寸标注、标题栏、修订记录一样不少。

核心原则：**图纸的可信度来自制图规范，不来自蓝色。** 蓝底白线谁都会调，真正让人信的是粗细分明的线型、带箭头的尺寸线、右下角那张填满字段的标题栏。规范越齐，图越像真的。

> 和 `tech-schematic-poster` 的分工：那个是**发光的屏**（CRT 荧光、扫描线、辉光溢出、等粗细线条）；这个是**印出来的纸**（纸纹、折痕、墨色不匀、线型分级）。两者载体不同、语法不同，不要互相借用元素——蓝图上不许有辉光，终端上不许有折痕。

## 三种画幅

| | 封面 Cover | 插图 Inline | 图纸 Sheet |
|---|---|---|---|
| 目标 | 首屏砸眼、可点击 | 讲清一个段落 | 就是一张图纸本身 |
| 画幅（锁死） | **5:2 横板** | **16:9** | **3:2 横板**（A3 比例） |
| 主标题 | 巨型渲染进画面 | 极少量拉丁小标，或无 | 无大标题，标题只在标题栏里 |
| 制图装置 | 全套但压暗 | 精简 | 全套且完整，是主角之一 |

## 三种纸张寄存器（PAPER REGISTER）

一次选一个，整篇统一，不混用：

- **CYANOTYPE（默认）**：深普鲁士蓝底 + 白色线条。经典晒图，最有年代感和辨识度。
- **WHITEPRINT（可选）**：米白纸底 + 深蓝线条。现代重氮复印图。信息密度高、标注多的时候比蓝底更好读。
- **SEPIA（可选）**：陈年棕黄纸 + 深褐线条。档案、历史、老专利图的感觉。

用户没指定用 CYANOTYPE。

## 四种图面模式（DRAWING MODE）

这是本 skill 的主干，按内容选，别默认全用第一种：

| 内容是什么 | 用哪种 | 长什么样 |
|---|---|---|
| 流程、系统、分工、工作流 | **TOPOLOGY** 流程拓扑 | 节点-连线图，入口 → 分支 → 汇合 → 出口，带引线标注 |
| 一个具体物件、产品、工具 | **ORTHOGRAPHIC** 三视图 | 正视 / 侧视 / 俯视三个投影并排，中心线贯穿，全套尺寸标注 |
| 由多个部件组成的东西 | **EXPLODED** 爆炸图 | 部件沿一条轴线拉开，虚线对位，气泡编号配零件表 |
| 要放大讲某一处 | **DETAIL** 详图剖面 | 主图 + 圆圈框出局部 + 一侧的放大详图，带剖切符号和剖面线 |

抽象概念也要落到其中一种——讲「系统在漏」用 TOPOLOGY 画断开的边，讲「这个工具的三个面」用 ORTHOGRAPHIC，讲「它是由什么拼起来的」用 EXPLODED。

## 三档纸张质感（PRINT TEXTURE）

质感盖在图之上，永远不吃线条和字。整篇统一一档：

| 档位 | 给什么 | 加了什么 |
|---|---|---|
| PRINT-01 CLEAN | 标注密集的图纸、长标题封面 | 纸纹 + 轻微墨色不匀 + 边缘微褪 |
| **PRINT-02 STANDARD（默认）** | 封面和大多数插图 | 上一档 + 横向压印条带 + 两道折痕 + 四角压暗 + 浮尘 |
| PRINT-03 AGED | 讲旧、讲档案、讲被翻烂的东西 | 上一档 + 咖啡渍水渍 + 卷边撕口 + 四角图钉孔 + 手写红笔批注 + 复印重影 |

## Read

- 编译提示词：读 `references/compile-contract.md`（消歧义铁律 + 线型分级 + 制图装置清单 + 三寄存器和三档质感原文 + 固定骨架）。英文段落整段复制，不要自己重写。
- 要成品参考或批量做整篇：读 `references/examples.md`（封面 + 三视图 + 爆炸图的已决策成品 prompt）。

## Input

从用户输入推断，不要求填表：

1. **画幅**：封面 5:2 / 插图 16:9 / 图纸 3:2。
2. **图面模式**：TOPOLOGY / ORTHOGRAPHIC / EXPLODED / DETAIL。
3. **纸张寄存器**：CYANOTYPE（默认）/ WHITEPRINT / SEPIA。
4. **质感档**：PRINT-01 / PRINT-02（默认）/ PRINT-03。
5. **主标题**：用户原文照抄，不翻译不润色；中文主标建议 2-8 字。只有封面渲染大标题。
6. **图面内容**：把主题落成具体的节点 / 投影 / 部件，每一项都要有名字和编号。

## Workflow

1. **判画幅**：封面 5:2、插图 16:9、纯图纸 3:2。
2. **判图面模式**：按上面那张表选，一张图只有一个主模式。
3. **判寄存器和质感档**：默认 CYANOTYPE + PRINT-02；整篇一档到底。
4. **排线型**：轮廓粗、尺寸线细、中心线点划、隐藏线虚线、剖面线细密斜线。这条不排清楚，出来就是"蓝色的流程图"而不是图纸。
5. **装制图装置**：图框分区 + 右下标题栏 + 修订表 + 尺寸标注 + 气泡编号 + 比例尺，按画幅决定装几件（封面压暗、图纸全上）。
6. **编译提示词**：按 `compile-contract.md` 的固定骨架输出成品，无占位符、无菜单、正文零中文（渲染标题除外）；PRINT TEXTURE 段整段照抄。
7. **输出**：画幅 + 模式 + 寄存器 + 质感档 + 一条完整提示词 +（可选）一句选型理由。用户只要 prompt 时省略解释。

## Quality Gates

- **线型必须分级**：所有线一样粗 = 出图失败。轮廓、尺寸、中心、隐藏四种线视觉上要能分开。
- **标注要成立**：尺寸线两端有箭头、有延伸线、有数字；引线指向具体位置；气泡编号能对上零件表。标注是装饰不是内容，但假装标注比不标注更糟。
- **标题栏不能空**：右下标题栏每一格都要有值，而且必须在 TEXT 段里逐条写成 `字段 / 值`（PROJECT / FLOW-01、TYPE / TOPOLOGY、SCALE / 1:1、SHEET / 01）。只在装置段写 `every cell filled` 模型会把字段名画上、右边留空——实测最高频的翻车点。
- **单一墨色**：一个寄存器只有一种线色，最多一个强调色（红笔批注只在 PRINT-03 出现，且只有它可以是第二色）。
- **不许出现屏幕元素**：辉光、bloom、扫描线、荧光绿、HUD 面板、系统日志——那些属于 `tech-schematic-poster`，出现即串味。
- 质感不吃内容：缩略图状态下主标题、节点名和标注数字仍然认得出来。
- 主标题精确渲染，中文标题用用户原文，不出现假中文字；次级小字用拉丁字段标签和数字。
- 不生成看起来像真实可读技术文档的大段文字；标注是短标签和数字，不是句子。
- 本 skill 只产出提示词，不编造已生成的图片结果。
