# Paper Workflow Hero

奶油纸底 + 三种质感共存的流程叙事主视觉。核心不是某一种材质，而是**三种渲染语域在同一张图里各守边界**。

## 风格 DNA（七项，任何主题不变）

1. **三语域共存且互不侵蚀**：扁平 UI 卡片（哑光米白、圆角、弥散投影、细线图标、无渐变）／写实拟物道具（可见布纹、金属、纸边，真实接触阴影）／半写实绘画人物（暖肤色、软笔触边、细画布颗粒，非照片）——三者边界必须分明，任何一种质感蔓延到另一域，风格即塌；
2. 背景是**单一奶油纸色**，仅极轻纸纹，零杂物零渐变；
3. **单一紫色贯穿**所有连线、图标、勾选、徽章；高饱和暖色（橙）全图只允许出现一次（便利贴）；
4. 连线是**圆角直角紫色流程线 + 小实心箭头**，单一清晰的阅读顺序，一条回流环；
5. 核心隐喻由**一件写实拟物道具**承载（卡片目录盒、木抽屉、活字盘……），它是全图质感锚点；
6. 人物与流程图**共处同一物理空间**，注意力落在图上，**主要人物不看镜头**——这是缝合两个世界的机关。人数、位置、姿态、动作、裁切方式全部自由；
7. 大衬线标题（近黑墨绿）+ 小衬线 tagline 中**单个词换品牌紫**。

第 1 条最容易丢：模型默认会把整图统一成一种质感（全 3D 或全插画）。第 6 条其次——人物一旦看向镜头，图就断成两半。

## 多样性纪律

DNA 七条固定，**舞台调度必须每张都换**。

首轮五图实测：三语域分离、单色贯穿、文字渲染全部成立，但五张的版式、人物位置、姿态、裁切和桌面道具几乎完全相同——因为初版母版把源图的一次调度决策写成了固定值。

现在调度拆成三张模块库（版式 / 人物 / 桌面道具，见 `references/from-scratch.md`）。**每次生成从三张表各抽一项，且与最近一次不同**；成组产出时先把整组的抽取结果列出来，确认无重复再编译。

## 模式判别

- 用户给**主题**要从零生成 → `references/from-scratch.md`（母版 + 道具/色板/人物模块库）
- 用户要**能整段发给别人、对方只填主题就能用的版本** → `ARTICLE-COPY.md`
- 用户给了**同风格参考图**要做同款 → 仍走母版，只把参考图里的内容决策（写什么字、几张卡、什么道具）填进空槽，制作手法一律用母版的

## 提示词书写规则

七段带标签，按此顺序：**Use case / Scene / Subject / Key details / Composition / Text in image / Constraints**。

排除项并进 `Constraints` 段，**不单独输出负面提示词块**——GPT Image 2 没有 negative 通道。

画面文字逐字放引号并给位置与字体特征，加 `render all text verbatim, no extra words`。文字多是这个风格的固有属性（标题 + 卡片标签 + 徽章 + tagline），文案越短越稳，每张卡标签控制在 1–2 个词。

画幅默认 5:2 横板（hero 用），16:9 可用；方图会挤压左右叙事，不推荐。

## Guardrails

- 风格用视觉特征描述，不指名艺术家、不复刻真实品牌 logo（Discord/Slack 等图标一律泛化为 chat bubble / envelope 等通用图形）。
- 人物是虚构泛型人物；用户要求画真人须本人同意。
- 出图偏差先怀疑 Subject 槽点名不足，不要动 DNA 固定块；一轮只改一处。
