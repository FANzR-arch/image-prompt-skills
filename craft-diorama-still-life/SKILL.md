# Craft Diorama Still Life

把内容编译成温暖、有触感的实物隐喻静物图：剪纸／手作微缩质感，**一个实物替一句判断**。

本 skill 同时覆盖文章封面（5:2）和章节／小节配图（16:9）。判断用户要哪一种，或两种都做。

## 意图判断

只在真的分不清时才问，否则直接从请求推断：

- 「封面」/「cover」/「主图」/「hero image」→ **封面模式**，一张 5:2。
- 「章节图」/「每节配图」/「chapter images」/ 给了文章路径并说「每一节」→ **章节模式**，每个主 `##` 章节一张 16:9。
- 只说「配图」，或「封面和章节都要」→ 两种都做：先一张封面，再逐章一张。

用户明确指定了画幅（4:5、1:1、16:9 封面等）就用用户的，不要强推默认值。

## 语言确认（仅封面模式）

写封面提示词之前，先问一句标题和副标题用中文还是英文，等回答。章节图永远不带大标题，无论封面什么语言，都只保留稀疏的英文小标签。

## 调色板

调色板是**角色制**的，不绑定任何具体品牌。六个角色：

| 角色 | 作用 |
| --- | --- |
| Ground | 主背景／主承载面，画面绝对主色 |
| Signal | 唯一的主动作、关键标记、被点亮的那个状态 |
| Support | 柔和的支撑卡片、面板、浅色表面 |
| Accent A | 极小面积的提醒／社群点缀 |
| Accent B | 状态点、时间胶囊、进度条 |
| Anchor | 唯一一个压场的深色实物、结构锚点，也可作标题色 |

用色纪律：Ground 绝对主导；Signal 只出现在一个明确焦点上；Anchor 只落在**恰好一个**实物上，不能铺成大色块；Accent A / B 只做小面积点缀；不额外引入霓虹、赛博朋克配色。

用户给了品牌色就映射到这六个角色；没给就用 `references/palette-contract.md` 里的预设，映射规则和预设都在那份文件里。

## 输入读取

给了本地文章路径就先读全文（终端可能吞中文时显式按 UTF-8 读）。抽出：标题、核心论点、最强的那处张力、承诺、逐章的隐喻（章节模式），以及任何能当小细节用的具体信号、数字、时间戳和短标签。

没给路径就用聊天里给的正文或主题。

## 产出约定

给了本地文章路径或用户要文件时，写一个独立 Markdown 文件；否则直接在回复里用同样结构。

封面文件名：`[文章名]-diorama-cover-prompt.md`
章节文件名：`[文章名]-diorama-illustration-prompts.md`
默认存在源文章旁边，除非另有指定。

封面文件结构：

```markdown
# Diorama Cover: [文章标题]

## Source
## Cover Strategy
[选定的物件域、隐喻、焦点实物、确认的语言、调色板映射]
## Cover Prompt
[一条完整可直接复制的提示词，标题文字直接写进去]
## Cover Copy Fallback
[只有反复生成都糊字时才需要：留白构图说明 + 后期合成用的准确标题副标题]
## Negative Prompt
## Acceptance Checklist
```

章节文件结构：

```markdown
# Diorama Illustrations: [文章标题]

## Chapter Prompt Map
| 章节 | 物件域 | 焦点实物 |
## Chapter 1 Prompt
## Chapter 2 Prompt
...
## Universal Negative Prompt
## Acceptance Checklist
```

只要聊天输出时，保持同样的结构。

## 固定规则

- 目标模型：GPT Image 2（其他生图模型同样可用，提示词不变）
- 封面 5:2 横版，章节图 16:9 横版
- 风格：剪纸／手作微缩静物，轻拟物，高级编辑设计感——不是摄影
- 背景：Ground 色
- 封面文字：标题／副标题按确认的语言直接烧进画面，小标签保持英文；章节图只有稀疏英文小标签，无大标题
- 不出现任何 logo
- 纯色，无渐变
- 自然柔和的投影，材质要有真实触感

## 选物

先从这篇内容自己的隐喻里长出焦点实物和配角实物。**不要每次都伸手去拿同一批道具**——讲速度的和讲信任、记忆、证据、规模的，不该落到同一个物件上。

章节模式里，同一篇文章里任意两章不共用焦点实物，也不复用封面已经用过的。封面模式里，避开这个项目最近 2-3 张封面用过的物件。

先定物件域再定具体物件，并且轮换物件域——别让一个项目里的所有图、或一篇文章里的所有章节，都沉到同一个域里。完整域库和轮换规则见 `references/object-domains.md`。

只有内容真的需要屏幕时才用笔记本或手机，它不是默认主角。

## 场景与特效纪律

环境要克制。焦点实物加 3-6 个配角细节就是全部画面——**不要**在周围搭出完整的地景、地形或舞台（小径、碎石、岩块、植丛、背景布景）。一片素净或极轻微纹理的 Ground 底就够了；只有隐喻本身要求「站在这片地上」时才加地面质感，加了也要极少。

一切保持静止。这是静物／产品摄影式的物件研究，不是动作场面：不要运动拖影、不要撞击火花、不要发光爆闪、不要光线射线、不要碰撞或摩擦效果、不要扬尘。物件靠位置和成色暗示状态（正在过渡、刚被放下、彼此咬合、静置），绝不靠加特效。

## 文字规则

**封面**：标题和副标题按确认的语言写进提示词，并且**真的生成在画面里**——不要默认留一块空白区。确认中文就把准确中文写进提示词，生成后检查有没有糊字，先重生成；只有反复重生成都糊才退回留白构图＋后期合成。小装饰标签（时间戳、数字）无论标题什么语言都可以保持英文。

**章节**：只用稀疏英文小标签——时间戳（`4:12`）、数字（`300+`、`24h`）、时间轴胶囊（`T+24h`）、短标签（`Ready`、`Resolved`、`Context`）。无大标题、无中文、无长段落、无密集 UI 文案、无伪造表格。

## 提示词书写顺序

1. 画幅和目标模型
2. 风格与调色板：六角色配色、剪纸微缩、轻拟物、高级编辑设计感
3. 核心／本章隐喻：一句话
4. 焦点实物：1-2 个主体，来自选定的物件域
5. 配角细节：3-6 个小道具，环境克制
6. 文字：封面用确认语言的标题，或本章的稀疏英文标签
7. 护栏：无其他语言文字（按模式）、无 logo、无渐变、无场景搭建、无运动／撞击特效

每条提示词都要完整、可直接复制——不要把关键约束拆成含糊的备注让用户自己拼。

## 默认负面提示词

```text
Text in a language other than confirmed (cover) or non-English text (chapter), brand logo, watermark, people, faces, hands, oversized laptop, oversized smartphone, dense dashboard, full table, cluttered desk, too many unrelated objects, elaborate landscape or terrain staging, scenic environment beyond the object and its immediate props, dark cyberpunk, neon glow, gradients, motion streaks, impact sparks, glow bursts, light-ray effects, collision or friction effects, dust explosions, black background, stock photo, mascot, excessive 3D, messy typography, long paragraphs
```

## 验收清单

收工前逐条核对：

- 封面写明 `5:2 horizontal`，章节图写明 `16:9`（或用户指定的画幅）
- 封面：标题／副标题是烧进画面的可见文字，语言与确认一致——不是留白
- 章节：只有稀疏英文标签，没有大标题
- 1-2 个焦点实物，来自贴合内容的物件域，章节之间和与封面之间都不重复
- 没有地景搭建，画面是静止静物，无运动／撞击／发光特效
- 没有 logo
- 六个调色角色都写明了落在哪，负面提示词已附上
