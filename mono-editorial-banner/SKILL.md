# Mono Editorial Banner（黑白编辑横幅编译器）

把**一句判断**编译成**一条**可直接交给图像模型的提示词。风格锁死：纯白虚空里放一个写实主体，主体自身带出纯黑作为画面唯一的黑色锚点，超大衬线主标题压在画面上方。

核心原则：**一句话，一个物件，一块黑。** 这套风格的高级感不来自元素多，来自影调纯度和克制——白就是纸白、黑就是墨黑，画面里只有一个东西被照亮。加第二个主体、让灰调爬满画面，风格立刻塌。

## 画幅

**5:2 超宽横板锁死。** 出图参数用 `3200×1280`、quality `high`——发丝衬线和细线地面都吃分辨率，低分辨率下这套风格必糊。

其他画幅未经验证；用户明确要求才改，并提醒留白比例需重新量。

## 两种语言寄存器（Register）

一次选一个，整组统一。**两个寄存器的所有渲染文字都是衬线体**，这是本风格的身份特征。

- **EN（默认）**：主标题 Didone 衬线（Bodoni 类），极端粗细对比 + 发丝衬线；descriptor 小号宽字距衬线大写。
- **CN**：主标题高对比宋体（标宋 / 报宋类），横细竖粗、尖锐三角衬角；descriptor 小号宽字距宋体。

用户给的标题是什么语言就用哪个寄存器，不翻译不润色。中文另有生成风险，见 `compile-contract.md` 的中文渲染专项。

## Read

- 编译提示词：读 `references/compile-contract.md`（铁律 + 锁死内核 + 两语言寄存器 + 固定骨架）。
- 选主体装置、要成品参考、或成组批量做：读 `references/examples.md`（主体词汇表 + 已验证成品 prompt）。

## Input

从用户输入推断，不要求填表：

1. **主标题**：用户原文照抄。EN ≤4 词（最多 6），CN ≤8 字。这是画面第一视觉焦点。
2. **descriptor**：主标题上方的小字标签。EN ≤3 词，CN ≤6 字。用户没给就按主标题的语境拟一个。
3. **主体装置**：把这句判断压成一个能叫出名字的实物。查 `examples.md` 的主体词汇表。
4. **寄存器**：跟主标题语言走。

## Workflow

1. **读判断**：先说清这句话讲的是什么**关系**（对置 / 承重 / 积累 / 连锁 / 选择 / 复利……），关系决定装置。
2. **选装置**：查主体词汇表。一张图只能有一个主导装置，可以带内部层次（一个主物件 + 若干配角），不能有两个平权主体。
3. **定黑色锚点**：这个装置里，**哪一块是纯黑**？没有明确的黑锚点就换装置——这是本风格的承重墙。
4. **定受光对象**：整个画面只有一个东西被照亮，其余沉进白或黑。这是第二块承重墙。
5. **编译提示词**：按 `compile-contract.md` 的固定骨架输出成品，无占位符、无菜单、正文零中文（渲染标题除外）。
6. **输出**：寄存器 + 一条完整提示词 +（可选）一句装置选型理由。用户只要 prompt 时省略解释。

**成组产出时**：风格基座（Key details / Text 规格 / Constraints 三段）必须逐字写进**每一条**提示词——模型只看得见单条，共享规则不会自动继承。只有 Scene 情节、Subject 和文字变。

## Quality Gates

- **影调纯度**：背景是纸白、锚点是墨黑，灰只能出现在主体自身表面的窄过渡上，绝不能成为片区色调。出图发灰即失败。
- **单一受光**：一个装置里只有一处受光，其余沉入黑。多处打亮会把黑区切碎成灰色柱廊——这是本风格最常见的塌方点。
- **留白 ≥50%**：主体占下半部，标题占上部 30%，中间留净空。主体不得压住或遮挡文字。
- **文字平面化**：渲染文字是平面实黑图形，无阴影、无立体、无透视。带阴影的大标题立刻变廉价。
- **文字精确**：只出现指定的两行，必带 verbatim 条款。画面里出现第三行字、水印、logo 即失败。
- **中文必查乱码**：CN 寄存器出图后逐字核对字形，有错字或造字先重生成；反复失败才降级为留白 + 后期排字。
- 本 skill 只产出提示词，不编造已生成的图片结果。
